# Selection Sort in Go

A simple implementation of the [selection sort](https://en.wikipedia.org/wiki/Selection_sort) algorithm in Go.

## How it works

1. Find the smallest element in the unsorted portion of the array.
2. Move it to a new sorted array.
3. Repeat until all elements are sorted.

**Time complexity:** O(n²)

## Run

```bash
go run main.go
```
